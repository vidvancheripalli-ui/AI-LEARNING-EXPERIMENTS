# AI Engineering Journey

A project-driven journey to become a production-ready AI Engineer.

This repository documents my journey from understanding the foundations
of modern AI systems to building, deploying, evaluating, and scaling
real-world AI applications.

The goal is not to simply complete courses or collect technologies.

The goal is to understand how AI systems work underneath, build them
from scratch where appropriate, and progressively learn how to turn
those systems into reliable production software.

---

## 🎯 Objective

Build strong engineering depth across:

- LLMs and Transformers
- LLM application engineering
- Embeddings and semantic search
- Retrieval-Augmented Generation (RAG)
- AI agents and multi-agent systems
- AI backend engineering
- Production AI systems
- AI security and reliability
- Machine Learning
- Deep Learning
- ML systems and MLOps
- Multimodal AI
- Agent interoperability

By the end of this journey, I should be able to:

- Understand what happens underneath modern AI abstractions
- Build AI systems rather than only consume AI APIs
- Design reliable AI backends
- Build and evaluate RAG systems
- Build tool-using and multi-agent systems
- Deploy AI applications
- Reason about latency, cost, scalability, reliability and security
- Understand the ML/DL foundations behind modern AI
- Explain the architecture and engineering decisions behind my projects
